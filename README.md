## Sobre mí

Tomo un requerimiento, diseño la API y lo dejo funcionando en producción. Trabajo sobre todo con **React, Next.js, Node.js, TypeScript y PostgreSQL**, y me importa tanto la arquitectura como que la interfaz cargue rápido.

He construido módulos para un POS usado en restaurantes de **Colombia, México y Panamá**, un sistema de pago con QR para el transporte público de Tunja y productos propios con integración de **LLMs**. He presentado investigación en **7 eventos académicos**, entre ellos varios congresos internacionales.

**Abierto a roles Full Stack o Backend**: remoto, o con reubicación a Bogotá o Medellín.
